# HR-Attrition-and-performance-analytics
Project Overview

This project uses Power BI to analyse employee attrition patterns and explore workplace factors associated with employee turnover. The dashboard transforms HR data into actionable business insights and employee retention recommendations.

Objectives

Analyse overall and department-wise employee attrition.

Explore the relationship between attrition and overtime.

Examine job satisfaction, work-life balance, salary, and performance ratings.

Develop data-driven employee retention recommendations.

Present key findings through an interactive Power BI dashboard.

Tools & Technologies

Power BI

DAX

Microsoft Excel

Data Visualization

Key Features

Interactive HR analytics dashboard with KPI cards and slicers.

Department-wise attrition analysis.

Employee satisfaction and overtime analysis.

Performance and salary-related visualisations.

Business insights report with a retention action plan and 90-day implementation timeline.

Business Outcome

Provides HR teams with insights into employee turnover patterns and practical recommendations to support employee retention and data-driven decision-making.

Dataset

IBM HR Analytics Employee Attrition & Performance dataset.

Note

This is an independent portfolio project using a public HR analytics dataset. The analysis identifies attrition patterns and associated factors; it does not establish causation or directly measure declining productivity.
